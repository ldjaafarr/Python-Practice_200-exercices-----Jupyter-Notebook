# أذكار الصباح ☀️

تطبيق أندرويد بسيط مبني بـ **React Native (Expo)** يعرض أذكار الصباح من حصن المسلم مع عدّاد لكل ذكر.

## المميزات
- 23 ذكرًا من أذكار الصباح مع المصدر وعدد التكرار.
- اضغط على بطاقة الذكر لإنقاص العدّاد (مع اهتزاز خفيف).
- شريط تقدّم يوضح عدد الأذكار المنجزة.
- زر «إعادة البدء» لتصفير جميع العدادات.

## التشغيل
```bash
cd morning-adhkar-app
npm install
npx expo start
```
ثم امسح رمز QR بتطبيق **Expo Go** على هاتف الأندرويد، أو اضغط `a` لفتحه على المحاكي.

## بناء ملف APK
```bash
npm install -g eas-cli
eas build -p android --profile preview
```

## الملفات
- `App.js` — واجهة التطبيق.
- `adhkar.js` — نصوص الأذكار (يمكن تعديلها أو إضافة المزيد بسهولة).
